To call a tool, output a JSON object inside <tool_call>...</tool_call> with exactly the keys "name" and "arguments". For example:
<tool_call>{"name":"image_zoom_in_tool","arguments":{"bbox_2d":[100,200,500,600],"label":"region of interest","img_idx":0}}</tool_call>
After a tool call, wait for the tool response and its crop image before continuing. Tool responses appear inside <tool_response>...</tool_response> in a user turn.
